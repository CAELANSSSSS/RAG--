# RAG--
項目：檢索增強生成系統本地部署大模型之企業應用服務，以台灣亞洲大學資訊傳播學習為例

本地運算環境

本系統採用 GPU 加速進行大型語言模型推論，使 RAG 系統可以在本地端完成知識檢索與 AI 回答生成。

本地部署的主要優點包括：

* 降低對第三方雲端 API 的依賴
* 提高企業資料掌控能力
* 支援內部私有知識庫
* 可依硬體資源進行模型與效能調整
* 具備後續企業內部部署的擴充性
